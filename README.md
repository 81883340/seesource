# SeeTV 频道列表

## 📺 项目说明
本仓库自动同步自 [tv.jun1985.cn](https://tv.jun1985.cn) 的 M3U 频道列表，每6小时更新一次。

## 📁 文件说明
- `m3u_files/current.m3u` - 最新的 M3U 格式频道列表
- `backups/` - 历史版本备份目录
- `last_update.json` - 最后更新信息

## 🔗 使用方式
在播放器（如 PotPlayer、VLC、Kodi 等）中使用以下链接：
```
https://raw.githubusercontent.com/81883340/SeeTV/main/m3u_files/current.m3u
```
